# Remix of Adviser Connect

Build a polished, responsive web application prototype for a study-abroad adviser marketplace called Infinity.

Infinity helps Bangladeshi students find, compare, and book verified study-abroad advisers for university selection, scholarships, SOP feedback, visa preparation, and the overall application process.

Brand direction

Create a premium, trustworthy, modern, and professional visual identity.

Use these primary colors:

Primary teal: #176A6E

White: #FFFFFF

Light background: #F5F8F8

Dark text: #152223

Secondary text: #657576

Light teal border: #D8E7E7

Success color: #2F8F69

Warning color: #D99B42

The design should mainly use white backgrounds with #176A6E for buttons, links, icons, badges, active navigation states, and important highlights.

Avoid excessive gradients. Use clean solid colors, subtle shadows, soft borders, and generous whitespace.

Typography

Use typography inspired by the clean, premium, modern style of the BMW website.

Do not use BMW’s proprietary font. Use Manrope as the main font, with Inter as the fallback.

Font stack:

Manrope, Inter, Helvetica, Arial, sans-serif

Typography style:

Large, bold, confident headlines

Clean uppercase labels where appropriate

Medium-weight navigation

Highly readable body text

Spacious line height

Minimal decorative typography
